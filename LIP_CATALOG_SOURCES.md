Data limitations:
- Supplied numbered photos are assigned by their series and file code. Some photos are visually reused or unlabeled, so their actual correspondence still requires store review.
- These identity references are not physical shade measurements. New rows have no fabricated HEX/undertone/depth and remain unreviewed for matching.
- New stock is zero until entered by the owner. Price follows an existing priced shade in that same product, when available; otherwise price is pending. Original IDs/prices/stocks and custom images are preserved.
- A migration reuses an existing exact shade code or known name within the same product, fills missing code/image fields, and never wipes the catalog. Legacy examples with different/incorrect names remain for manual review rather than deleting possible order-linked records.
- Archived/current market availability, exact formula version, image accuracy, physical suitability and inventory are not inferred from the supplied photos.
